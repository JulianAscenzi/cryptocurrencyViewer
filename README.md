# cryptocurrencyViewer
A cryptocurrency visualizer built to track and analyze real-time data for BTC, ETH, USDT, BNB, and SOL.

## Uso

```
npm install
npm start   # levanta el servidor web en http://localhost:3000
npm run cli # imprime los precios actuales en la terminal
```

La app web muestra precios y cambio 24h de las 5 monedas, un gráfico de historial (1d/7d/30d/90d/1a) y permite
configurar un umbral de alerta por moneda que avisa en la página cuando el precio lo cruza.
